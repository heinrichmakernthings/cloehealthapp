# Cloe's Cozy Club

A private, local-first health tracking web app with cute rewards and Biscuits interactions.

## Run locally
Open `index.html` in a browser.

## Deploy
This is a static site. You can deploy it to Netlify, Cloudflare Pages, GitHub Pages, or any static host.

## Data
User data is stored in browser `localStorage` under:

`cloeHealthQuestV1`

Keeping the same domain preserves the same browser-local data. Moving to a different domain requires using the app's backup/restore feature.

## Current features
- Daily check-ins
- Food / IBS logs
- Flare logs
- Edit/delete food and flare logs
- Home counters and recent entries
- Clues dashboard
- Data dashboard
- JSON backup/restore
- CSV / monthly summary export
- XP, streaks, rewards, loot, coupons
- Rotating countdowns
- Biscuits interactions and cute save feedback
